**Recipe Manager**

A web application designed to digitize, organize, and manage your personal recipe collection. This project provides a centralized platform for users to input, store, and retrieve their favorite meals without the clutter of physical cookbooks or scattered bookmarks.

Key Features:

- Comprehensive Recipe Logs: Input and save detailed meal information, including titles, preparation times, and serving sizes.

- Structured Data Entry: Add specific ingredient lists with measurements and log step-by-step cooking instructions.

- Cuisine Categorization: Tag and organize recipes by cuisine type, dietary preference, or meal category for quick filtering and retrieval.

- Responsive Interface: A clean, user-friendly dashboard that makes adding new recipes and reading cooking instructions seamless across devices.

Tech Stack:

Frontend: [Javascript, HTML, CSS]

Backend: [Node.js,/JSON]
